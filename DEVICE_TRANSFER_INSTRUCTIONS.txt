========================================================================
METRO PROBATI — DEVICE TRANSFER & SETUP GUIDE
মেট্রো প্রভাতী — নতুন ডিভাইসে সেটআপ নির্দেশিকা
========================================================================

আপনার নতুন কম্পিউটারে বা ল্যাপটপে প্রজেক্টটি চালু করার ধাপসমূহ:

ধাপ ১: আনজিপ (Extract) করুন
------------------------------------------------------------------------
- "metro-probati-platform.zip" ফাইলটি রাইট ক্লিক করে "Extract All..." বা আনজিপ করুন।

ধাপ ২: Node.js ইনস্টল আছে কি না চেক করুন
------------------------------------------------------------------------
- নতুন কম্পিউটারে Node.js (v18 বা v20 বা v22+) ইনস্টল থাকতে হবে।
- টার্মিনালে চেক করুন:
    node -v
    npm -v
- যদি ইনস্টল না থাকে, তবে https://nodejs.org থেকে Node.js LTS ইনস্টল করে নিন।

ধাপ ৩: প্রজেক্ট ফোল্ডারে টার্মিনাল খুলুন
------------------------------------------------------------------------
- টার্মিনালে ফোল্ডারে প্রবেশ করুন:
    cd metro-probati-platform

ধাপ ৪: ডিপেন্ডেন্সি ইনস্টল করুন
------------------------------------------------------------------------
- টার্মিনালে নিচের কমান্ডটি লিখুন এবং এন্টার দিন:
    npm install

ধাপ ৫: ডেভেলপমেন্ট সার্ভার চালু করুন
------------------------------------------------------------------------
- লোকাল সার্ভার রান করতে:
    npm run dev
- ব্রাউজারে প্রবেশ করুন:
    http://localhost:3000

ধাপ ৬: টেস্ট যাচাই করুন (ঐচ্ছিক)
------------------------------------------------------------------------
- সব ফিচার ও ক্যালকুলেশন ভেরিফাই করতে:
    npm test

ধাপ ৭: প্রোডাকশন বিল্ড ও রান (ঐচ্ছিক)
------------------------------------------------------------------------
- প্রোডাকশন বিল্ড করতে:
    npm run build
- প্রোডাকশন রান করতে:
    npm start

------------------------------------------------------------------------
লাইভ প্রোডাকশন ডিপ্লয়মেন্ট (Vercel):
- https://metro-probati-platform.vercel.app
